## [0.1.0] - 2026-09-13

Initial release.

- Typed repositories and Elasticsearch 8 and 9 client adapters.
- Struct mappings, field descriptors, code generation, lifecycle hooks and optimistic concurrency.
- Query builders, aggregations, facets, geo and vector search.
- Point-in-time pagination, resumable cursors and relationship loading.
- Bulk writes, item-level retries, streams and official bulk indexer adapters.
- Index administration, script updates, background tasks and checkpointed reindex migrations.
- Request observation, OpenTelemetry integration and application test fixtures.
- API reference, configuration guides and runnable examples.
